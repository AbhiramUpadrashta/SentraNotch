# Sentra Notch

**Your notch, now intelligent.** A free macOS app by [Bubbles Aro](https://bubbles.foo.ng) that turns the MacBook notch into a live, animated control centre.

- 🎵 Music from any app with album art, spectrum bars, waves or dancing outlines, controls and synced lyrics
- 🔊 Volume, mute, brightness and keyboard-light HUDs (optionally replaces the macOS pop-up)
- 🎧 **New:** Bluetooth pairing animation — mouse, keyboard, AirPods, headphones… spins for 2 s, then shows the battery
- 🔋 Charging, unplugged, full and low-battery live activities
- 📅 Today's calendar and reminders · 📷 camera mirror · 🗂️ file shelf with AirDrop · ⬇️ download activity
- 🎨 Themes (Midnight, Glass, Aurora, OLED), accent colours, gestures, global shortcuts
- 🔄 Built-in, signed "Check for Updates"

Requires macOS 14 Sonoma or later. Download: https://bubbles.foo.ng/SentraNotch/

Build: `bash build.sh` (Swift command line tools). MIT License © 2026 Abhiram Upadrashta.
Now-playing on macOS 15.4+ uses [MediaRemoteAdapter](https://github.com/ungive/mediaremote-adapter) (BSD-3-Clause).
